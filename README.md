Uma aplicação web ágil e direta ao ponto, desenvolvida para resolver uma dor real de profissionais autônomos: a perda de tempo na formatação de orçamentos. Com esta ferramenta, basta preencher os dados do escopo e o sistema gera automaticamente uma proposta comercial elegante, com os valores calculados e pronta para ser enviada ao cliente.

## ✨ Funcionalidades

*   **Cálculo Automático:** Multiplica dinamicamente as horas estimadas pelo valor da hora do profissional.
*   **Geração de Copy:** Cria um texto persuasivo e bem estruturado, padronizando a comunicação com o cliente.
*   **Clipboard API (Copiar com 1 clique):** Botão integrado que copia toda a proposta formatada diretamente para a área de transferência do usuário.
*   **UI/UX Moderna:** Interface estilizada em *Dark Mode* com paleta de cores Cyber (Ciano/Neon), proporcionando conforto visual e estética focada em desenvolvedores.
*   **100% Client-Side:** Não requer banco de dados ou backend, rodando inteiramente no navegador para máxima velocidade e privacidade.

## 🛠️ Tecnologias Utilizadas

*   **HTML5:** Estruturação semântica dos dados.
*   **CSS3:** Estilização com variáveis globais (`:root`), efeitos de transição (`hover`), animações suaves (`@keyframes`) e responsividade.
*   **JavaScript (Vanilla):** Manipulação da DOM, cálculos matemáticos, formatação de moeda (BRL) e integração com a API de Clipboard do navegador.
